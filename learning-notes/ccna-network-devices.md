# CCNA Learning Notes — Network Devices

## Study Focus

Current CCNA 200-301 study topic: foundational network devices and their roles in a network.

## Key Devices

- **Router** — connects different IP networks and forwards packets using routing information.
- **Layer 2 Switch** — connects devices within a LAN and forwards Ethernet frames using MAC addresses.
- **Layer 3 Switch** — combines switching with routing capabilities, commonly used for inter-VLAN routing.
- **Firewall** — enforces security policies by permitting or denying network traffic based on configured rules.
- **Wireless Access Point (AP)** — provides wireless devices with access to a wired LAN.
- **Wireless LAN Controller (WLC)** — centrally manages multiple wireless access points in enterprise networks.
- **Server** — provides services or resources to clients, such as DNS, DHCP, web, email, or file services.
- **Client** — an endpoint that requests services or resources from a server.

## CCNA Reminder

When studying network diagrams, identify each device by its role first, then determine what type of traffic it handles and which OSI layers are most relevant to its operation.
